## D. Build reference package for the selected karts

1. Write down the selected class, base and upgraded IDs and the matching
   sheet before making individual views.
2. Produce front, rear, left, right, top and underside orthographic views
   with a common scale, floor and axle center lines. Add front and rear
   three-quarter views so the form and part interfaces read clearly.
3. Identify the changed part IDs and show small close-ups of their mounts,
   panel seams and clearances. Use the project dimensions for the chassis.
   Measure the final mount positions on the actual model.
4. Claude uses the views to model the parts. Codex checks fit in the
   Driving Test against the seated rig and handling reference. The owner
   reviews the result.
