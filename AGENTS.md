# Shared entry point for project work

Use [CLAUDE.md](CLAUDE.md) for the shared, flexible working and communication
guide. Read [docs/HANDOFF.md](docs/HANDOFF.md) for current project status and
[docs/COLLABORATION.md](docs/COLLABORATION.md) for responsibilities and review.
These are the same sources used by Claude; do not maintain a second rule list.

Distinguish confirmed owner decisions from recommendations and unresolved
questions. Apply the owner's current request to the task; explain relevant
conflicts rather than silently expanding old instructions. A fresh session
preserves the existing game, approved work and checkpoints.
