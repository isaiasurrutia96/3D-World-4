# Universal Test Lab

The published workspace is `/test-lab/`. Its static UI lives in `public/test-lab/` and is copied to `dist/` by Vite.

`main.js` registers the existing live tests and their ready signals. One iframe is mounted at a time. The workspace forwards view buttons and mirrors each test's existing controls, keeping its model and motion code in its own app. When most of the viewer has scrolled away, its animation clock pauses and input is released; it resumes when the viewer returns.

Add future subjects to the test registry and selector. Prefer exposing the same ready flag, camera/view API and native controls used by the existing labs. Saved checkpoints remain separate and untouched.

This is the shared workspace for Codex and Claude Code. New tests must call `installTestLabScene` from `src/test-lab-scene.ts`, passing their renderer, scene, perspective camera, target getter and explicit floor/shadow objects. It activates only in the embedded lab (`?lab=...`), preserving standalone studies and frozen checkpoints. A test without a floor gets a separate presentation slab, sized to the subject (its widest footprint × 1.6, at least 3 m; `floorSize` overrides); never mark parts of the subject (such as island terrain) as the lab floor.

The toolbar has Front, Side, Back, Top, Angle, Isometric and Inspection. Isometric uses an orthographic camera with equal X/Y/Z foreshortening; Angle remains a perspective view. Inspection hides only the lab floor and its contact shadow, leaving simulation and subject geometry intact. This choice persists while switching subjects or resetting. Floors are solid neutral-grey `#8f9295` slabs, preserving each test's original width/depth and top/contact height, with at least 0.6 m thickness. Do not enlarge the floor to conceal rendering glitches. The orthographic render camera fits the entire slab between near/far planes independently of visible framing, including during mobile orbiting. Isometric framing shows 2.4 times more space in each dimension than the close inspection view. The full-width bottom toolbar area is off-white `#f4f1e9`, with neutral buttons and a charcoal selected state. Dragging or pinching keeps the wide orthographic mode active while orbiting or zooming, using each test's existing camera controls. In movement tests, the right side looks around and the left joystick still moves. Press Isometric again to reset to the equal-axis starting angle; choosing another view returns to perspective.

The toolbar wraps into two rows on small phones and respects safe areas in portrait and landscape. Page selection, long-press callouts and browser touch zoom are suppressed in both the shell and embedded viewer; model controls and native form controls remain usable. Keep device sizes, keyboard/mouse and touch covered when changing the shared UI.

Approved baseline: [Test Lab checkpoint 1](../checkpoints/test-lab-1/CHECKPOINT.json), saved 17 November 2026. Its preview is `/checkpoints/test-lab-1/` and its immutable Git tag is `test-lab-checkpoint-1-2026-11-17`. The archive includes its own tests, assets and videos, with every file hashed. Keep it unchanged; use this live workspace for future edits.

The video panel plays avatar-only walking and running captures, plus the earlier side-by-side reference comparison. Videos have native pause/seeking, three playback rates and downloads. Regenerate the avatar clips with `npm run build` followed by `node test-lab/capture.mjs` (requires Chromium and ffmpeg). The capture renders the existing motion through one whole cycle and encodes three cycles at the gait's normal speed; it does not author another animation.

After building, run `node test-lab/test.mjs` for phone layout, view selection, mirrored hand controls, native touch movement, off-screen pause, video playback/seeking and all subject loading checks. The browser harness uses `/usr/bin/chromium` and saves inspection screenshots only under `/tmp`.

The Motion button opens hand/foot presets, Play/Stop alongside the visible model. On phones the panel docks above the toolbar and reserves viewer space; on larger screens it docks at the right and reserves viewer width. It forwards the existing native pose controls and stays synchronized with controls below the viewer. Retapping the active preset returns that body part to rest; Stop returns the whole subject to rest. Closing with Motion, Close or Escape also stops playback and restores all hand/foot poses. There is no separate reset button in the panel. Motion is disabled for subjects without pose controls. New pose labs should expose native preset buttons and a play control so the same panel can be reused.

Run `node test-lab/motion-test.mjs` after building to verify pose toggle and close-to-rest behavior, model visibility, six screen layouts, dismissal and standalone hand/foot integration.
